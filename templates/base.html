Model Configuration

Main menu

All models are trained with Hugging Face's IMDB database.
In order to experiment with the precision in different texts there are 2 different DistilBERT configurations.
1. DistilBERT only with IMDB -> To compare to the classic models.
2. Distilbert trained with IMDB and fine-tuned with SST-2.

Train Neural Networks

In order to train the neural networks Google Colab has been chosen as the training enviroment.
The decision was based on the computing costs.
In case of a retrain the next steps will be needed:

1 - Download of .ipynb file for Google Colab.
2 - Open Google Colab's page.
3 - Create a new project with that file.
4 - Start the training.
5 - Download the .zip file after the training.
6 - Upload the compressed file into "Train Neural Networls"
