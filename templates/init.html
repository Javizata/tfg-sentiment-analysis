Welcome!

This App is oriented to implement and compare different algorithms of machine learning and a neural network to analyze the polarity (positive/negative) from the cinema reviews.
To achieve that the models are trained with Hugging-Face IMDB Dataset and Hugging-Face SST-2 Dataset (Rotten Tomatoes)
The main goal is to develop an interactive interface to show the evaluation of the models in Natural Language Processing (NLP)

The architecture is based on Flask, Git and Python for data processing.
