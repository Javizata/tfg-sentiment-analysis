Classic Models vs Neural Networks

Below are the different models trained for processing movie reviews. These models have been specifically trained using the IMDB and SST-2 datasets from Hugging Face. Thanks to this training, they allow sentiment detection positive or negative with high accuracy.
Specifically, the possibilities include 3 classic models versus 1 modern neural network.

Configuration

Logistic Regression

Linear statistical model used for binary classification problems. It is efficient, interpretable and works well when the relationship between variables is approximately linear.

Naive Bayes

Probabilistic classifier based on Bayes' theorem and the assumption of independence between variables. It stands out for its speed and strong performance in text classification tasks.

Support Vector Machine (SVM)

Supervised learning model that finds the optimal hyperplane separating classes maximizing the margin. It is effective in high-dimensional spaces.

DistilBERT

Transformer-based language model, optimized from BERT using distillation techniques. It maintains high performance in natural language understanding with lower computational cost.
